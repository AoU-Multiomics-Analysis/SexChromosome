# XYalign Implementation Plan

> **For agentic workers:** Use the design and complete all checks before opening the draft PR.

**Goal:** Add XYalign chromosome analysis and optional remapping for Terra.

**Architecture:** One WDL 1.0 workflow scatters over typed samples. A CLI wrapper validates localized files and uses stable task-local paths.

**Tech Stack:** WDL 1.0, Python, micromamba, GitHub Actions.

**Spec:** docs/superpowers/specs/2026-11-16-xyalign-design.md

## Global Constraints

Use WDL 1.0. Preserve File types until command rendering. Create files only in task scope. Do not use JSON as an argument wrapper. Log each command. Build no local Docker image. Do not submit cloud jobs. Do not merge the PR.

## Review Focus

- File localization must preserve explicit input dependencies.
- Shell metacharacters must not reach upstream shell strings.
- Missing or incompatible BAM and reference indexes must fail before computation.
- Both Y-status remapping branches must produce readable indexed BAMs.
- Image rebuild paths must contain only the wrapper script.
